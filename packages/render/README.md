# @infinitable/render

[infinitable](https://github.com/cabinet-fe/infinite-table) 高性能 canvas 表格引擎的渲染层：`createRenderHost` 多层画布宿主（ground/body/media/sky）、场景图与失效驱动的帧调度。core 仅经此处导出的 RenderHost 窄接口与渲染层耦合。

```bash
npm i @infinitable/render
```

文档、示例与性能对比见 [monorepo 根目录](https://github.com/cabinet-fe/infinite-table)。
