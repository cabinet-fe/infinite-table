# @infinitable/plugins

[infinitable](https://github.com/cabinet-fe/infinite-table) 高性能 canvas 表格引擎的官方插件集：`SheetStore` 多表实例池（按格 O(1) 读写 + `batchUpdate` 大块写）、Chart.js 图表离屏出图经 cell 级 MediaCache 位图路由上屏、快照/恢复等。

```bash
npm i @infinitable/plugins
```

文档、示例与性能对比见 [monorepo 根目录](https://github.com/cabinet-fe/infinite-table)。
