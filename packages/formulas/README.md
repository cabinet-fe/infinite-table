# @infinitable/formulas

[infinitable](https://github.com/cabinet-fe/infinite-table) 高性能 canvas 表格引擎的公式引擎：A1 引用解析、Pratt 解析求值、47 个内置函数、7 种错误值、依赖图（宿主驱动增量重算）与容错引用扫描；四则与 SUM/AVERAGE/ROUND/ABS 走 `@cat-kit/core` 精确计算。

```bash
npm i @infinitable/formulas
```

文档、示例与性能对比见 [monorepo 根目录](https://github.com/cabinet-fe/infinite-table)。
