# @infinitable/core

[infinitable](https://github.com/cabinet-fe/infinite-table) 高性能 canvas 表格引擎的核心包：`ListTable` 表格模型、全量虚拟滚动（构造与首次渲染只处理可视区，100 万行 TTFF 不劣化）与 Excel 式交互（选区/填充/冻结/合并单元格/键盘导航/编辑器注册表）。

```bash
npm i @infinitable/core
```

文档、示例与性能对比见 [monorepo 根目录](https://github.com/cabinet-fe/infinite-table)。
