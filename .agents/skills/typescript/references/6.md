# TypeScript 6.x

本文件适用于 **6.x**（JS 实现的末代编译器，仍有稳定 programmatic API）。不要用 7.0 才有的：原生 Go `tsc`、`--checkers` / `--builders` / `--singleThreaded`、模板字面量按 Unicode 码点切分、假定 `import ts from "typescript"` 不可用。

6.0 是迁 7 的桥。弃用项必须清掉；`ignoreDeprecations: "6.0"` 只是权宜，7.0 不认。

## 先清弃用（迁 7 必做）

| 弃用 | 改成 |
| --- | --- |
| `module Foo {}` 当 namespace | `namespace Foo {}`（`declare module "x"` 仍合法） |
| `import … assert { type: "json" }`（含 `import()` 的 `assert`） | `with { type: "json" }` |
| `moduleResolution: "node"` / `"node10"` / `"classic"` | Node 用 `nodenext`；bundler/Bun 用 `bundler` |
| `target: "es5"`、`downlevelIteration` | ≥ ES2015；还要 ES5 走外部编译器 |
| `module`: `amd` / `umd` / `system`（博客作 `systemjs`）/ `none`、`outFile` | `esnext` / `preserve` + bundler |
| `baseUrl` | 删掉，把前缀写进 `paths`（`baseUrl` 不再当解析根） |
| `esModuleInterop` / `allowSyntheticDefaultImports`: `false` | 删；CJS 默认导入用 `import x from "x"` |
| `alwaysStrict: false` | 删；不要把 `await`/`static` 当普通标识符 |
| `/// <reference no-default-lib="true" />` | `--noLib` 或 `libReplacement` |

用 `tsc` 且有 `tsconfig.json` 时，`tsc foo.ts` 会报错。真要忽略配置：`tsc --ignoreConfig foo.ts`。

## 新默认（6.0 已生效，不是等到 7）

- `strict`: `true`
- `module`: `esnext`
- `target`: 当年稳定 ES（6.0 时为 `es2025`，浮动）
- `noUncheckedSideEffectImports`: `true`
- `libReplacement`: `false`
- `rootDir`: 含 tsconfig 的目录 `./`（不再推断公共源码根）。源码在 `src/` 就显式 `"rootDir": "./src"`，否则 emit 会变成 `dist/src/`。
- `types`: `[]`。Node 全局写 `"types": ["node"]`，测试再加 `jest`/`mocha`。不要图省事用 `["*"]`，除非在迁。

`bundler` 现可与 `"module": "commonjs"` 组合（从 `node10` 迁出的过渡）。新项目仍优先：`"module": "preserve"` + `bundler`，或 `"module": "nodenext"`。

## 语言与 lib

无 `this` 的函数（含 method 语法但没用 `this`）不再当 contextual sensitive。箭头 vs method 的推断差异缩小；不要为「method 推断失败」再强行改成箭头。

Node 20+ / bundler 下 `package.json` `"imports"` 可用 `#/`：

```json
{ "imports": { "#/*": "./src/*" } }
```

```ts
import { util } from "#/util.js"
```

`target` / `lib`: `es2025`。ES2025 **没有新语法**；lib 含 `RegExp.escape`，并从 `esnext` 挪入 `Promise.try`、`Iterator` / `Set` 方法。

```ts
RegExp.escape(userInput)
await Promise.try(() => maybeThrow())
```

`Temporal`、`Map`/`WeakMap` 的 `getOrInsert` / `getOrInsertComputed`：类型在 `esnext` / `esnext.temporal`。有运行时再用，不要只为类型去 polyfill。

```ts
const v = map.getOrInsert("k", 0)
const w = map.getOrInsertComputed("k", () => expensive())
let t = Temporal.Now.instant()
```

`"lib": ["dom"]` 已含 iterable / asynciterable。不要再叠 `dom.iterable`。

## `--stableTypeOrdering`

迁 7 前打开，让 6 的类型排序对齐 7（否则 `.d.ts` / 偶发错误会对不齐）。日常 6.0 **不要常开**（官方：最多约 25% 变慢，不是长期功能）。7.0 强制开且关不掉。对齐时若出现新推断错误，补显式类型参数或变量注解。
